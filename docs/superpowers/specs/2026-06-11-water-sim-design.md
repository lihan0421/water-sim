# 真实水体仿真项目设计（water-sim）

日期：2026-06-11
状态：已确认

## 目标

构建一个浏览器端实时水体仿真演示项目，包含大海、河流、水槽三个场景，支持驾驶船只、投掷物体、参数调节三种交互，呈现视觉真实的海浪、浪花泡沫、船行激波与浮力物理。

## 定位与约束

- **平台**：Web，Three.js（WebGPURenderer + TSL）+ Vite + TypeScript，仅支持 WebGPU（新版 Chrome/Edge），单一代码路径。
- **真实度**：视觉真实为主——采用实时图形学方法（FFT 频谱海浪 + 波动方程），物理上为合理近似，不追求 CFD 级精确。
- **依赖**：lil-gui（参数面板）、stats.js（帧率）。不引入物理引擎，浮力/刚体自实现。
- **项目位置**：`D:\code\SJTU\water-sim\`，仓库内独立子项目。

## 架构：统一分层高度场

水面 = 两层高度场叠加，三个场景共用同一套管线：

### 环境波层（FFT 频谱海浪）

- JONSWAP 频谱 + 方向扩散函数生成初始频谱 h0(k)。
- 每帧 compute shader 计算时变频谱 h(k,t)，IFFT（ping-pong 蝶形变换）输出：
  - 位移图（含水平 choppy 位移）
  - 法线图
  - Jacobian 折叠泡沫遮罩（白帽）
- **3 级联**：约 250m / 60m / 15m 波长域，兼顾远海大涌与近处碎波，采样时按距离混合避免重复感。
- GUI 可调：风速、风向、浪高（频谱缩放）、choppiness。

### 交互波层（2D 波动方程）

- 512×512 高度场，compute shader 迭代 `∂²h/∂t² = c²∇²h`（含阻尼项）。
- 网格跟随主体（船或相机）平移，平移时内容随偏移重采样。
- 扰动源写入：
  - 船体沿水线投影写入移动压力扰动 → 自然形成船首开尔文波 + 船尾尾迹。
  - 物体落水按动量写入凹陷 → 环形涟漪扩散。
- 场景差异：水槽边界反射（墙壁反弹波）；河流叠加平流项（波纹顺流漂移）；大海开放边界（边缘阻尼吸收）。

### 合成

顶点着色器中两层位移相加；法线在片元着色器中混合。

## 三个场景

| 场景 | 环境波 | 交互波 | 特有元素 |
|------|--------|--------|----------|
| 大海 ocean | FFT 全开 | ✓ 开放边界 | 无限海面（同心环网格 LOD，中心密外圈疏）、天空盒、可驾驶帆船、白帽泡沫 |
| 河流 river | FFT 弱化为细纹 | ✓ + 平流 | 河道地形、流向贴图（滚动法线模拟水流）、漂浮物顺流而下、小船 |
| 水槽 tank | 关闭 | ✓ 边界反射 | 玻璃槽体（透视水线与折射）、投球/箱子、观察波的反射干涉与浮力 |

场景切换通过 UI 完成，各场景为独立模块，实现统一的 Scene 接口（init / update / dispose / gui 注册）。

## 浮力与船只物理

- **Floater 组件**：漂浮物底部布 4~16 个采样点；每点查询水面高度，按浸没深度计算浮力 `F = ρg·V排`，叠加线性/角阻尼与波面切向拖拽力；对质心积分合力与扭矩，得到刚体位置与姿态。船随浪起伏、小球入水弹跳后摇摆漂浮均由此涌现。
- **水面高度查询**：FFT 位移图 + 交互波高度图异步 GPU 回读（1 帧延迟，物理上可接受），CPU 侧双线性采样。
- **船只控制**：键盘 WASD 控制推力与舵向，推进力作用于船尾；航行时持续向交互波层写入扰动。
- **碰撞**：仅做物体—边界碰撞（水槽墙壁、河道岸壁）与简单球—球碰撞，不引入完整碰撞引擎。

## 渲染与浪花泡沫

- **水面着色（TSL 节点材质）**：Fresnel 反射（天空盒 + 太阳镜面高光）、基于深度的吸收折射（蓝→绿渐变）、浪尖次表面散射近似。
- **泡沫三来源**：
  1. FFT Jacobian 白帽——大海浪尖自动起沫；
  2. 泡沫累积纹理——船迹、涟漪处注入泡沫值，随时间衰减（船尾长白色尾迹）；
  3. GPU 粒子浪花——物体入水、船首破浪时的喷溅水花（实例化 sprite，compute 更新）。
- 水槽侧面透过玻璃可见水线与折射。

## 错误处理

- 启动时检测 WebGPU 支持，不支持则显示明确的提示页（要求新版 Chrome/Edge）。
- GPU 回读失败/延迟时浮力退化为使用上一帧高度，不中断仿真。

## 测试策略

- **vitest 单测**（CPU 侧纯函数）：
  - JONSWAP 频谱公式数值正确性；
  - 浮力积分器——静水中球体的平衡浸没深度与解析解对比；
  - 波动方程 CPU 参考实现——能量不发散、对称扰动产生对称波形。
- **视觉验收清单**（手动）：每场景一组检查项，如"船静止时随浪起伏无抖动""球落水涟漪到墙反射干涉""船尾迹泡沫随时间消散"。

## 不做的事（YAGNI）

- WebGL2 回退、移动端适配。
- FLIP/SPH 粒子流体（水槽用波动方程足够）。
- 完整物理引擎、复杂碰撞。
- 屏幕空间反射（SSR）——天空盒反射足够；后续可加。
